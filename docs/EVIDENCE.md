# Evidence capture

Copy this outline into an idea's `evidence/` directory and replace every placeholder before review.
Only publish observations and artifacts you have read and have the right to share.

```markdown
# Observation title

- Observed on: YYYY-MM-DD
- Claim tested: the precise question
- Environment: software versions, platform, configuration relevant to the result
- Method: reproducible command or procedure, with credentials omitted
- Sample: number of runs/items, selection method, and observation window
- Result: actual output and counts, including failures
- Source: public immutable link or sanitized attached capture
- Limits: what this observation cannot establish
- Independence: who ran/reviewed this and their relationship to the author
```

For a financial observation, also state currency, period, gross versus net, conversion method,
refunds and fees, and how founder/test purchases were excluded. A valuation, internal transfer,
or unpaid invoice is not a customer payment. Do not publish buyer identities or account exports.

For code artifacts, declare original source, license, modifications, environment, and the command
actually run. Preserve the license required by the original author. Link incompatible artifacts
instead of relicensing them. A file existing is not evidence that it runs.
